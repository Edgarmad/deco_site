## Nota de interpretacion

Las imagenes de `PANEL SPC/Paneles SPC 400V` se asignan tentativamente a `PLAFON PVC / 3 METROS` por color, pero la medida no esta demostrada por el nombre de la carpeta.
Las imagenes de Deck se guardan por color individual, mientras el Excel canonico define dos combinaciones (`Teca/Maple` y `Nuez/Redwood`); se marcan como parciales.
La fila duplicada del Excel es `ACCESORIOS / Soclo SPC / Humo`; Supabase conserva una sola opcion canonica.
